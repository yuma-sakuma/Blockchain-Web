# 🎨 Use Cases: Frontend Layer

> เอกสารนี้รวบรวม Use Cases ที่ทำงานในระดับ **User Interface (UI / UX)**  
> เน้นการโต้ตอบกับผู้ใช้, การนำเสนอข้อมูล และการเชื่อมต่อกับ Wallet

| ID | Use Case | บทบาท (Role) | รายละเอียดทางเทคนิค (Frontend) |
|---|----------|-------------|------------------------------|
| ALL | การเชื่อมต่อ Wallet | All Roles | ระบบ Login ด้วย MetaMask หรือ Wallet อื่น ๆ |
| ALL | หน้า Dashboard ตามบทบาท | All Roles | การจัดหน้าเว็บให้เหมาะสมกับสิทธิ์การเข้าถึงของแต่ละ Role |
| ALL | ระบบแจ้งเตือนธุรกรรม | All Roles | การแสดง Toast / Alert เมื่อส่ง Transaction และรอ Transaction confirm |
| A-03 | หน้า Dashboard แอดมิน | Admin | กราฟสถิติจำนวนรถ, ธุรกรรมรายวัน และการวิเคราะห์ภาพรวม |
| A-01 | หน้าจัดการ Roles | Admin | UI สำหรับค้นหา Address และกดปุ่ม Grant / Revoke Roles |
| M-01 | หน้าจดแจ้งผลิตรถใหม่ | Manufacturer | ฟอร์มกรอกข้อมูลรถ (VIN, รุ่น, สเปค) และปุ่มกด Mint |
| M-07 | จัดการรายการผลิต | Manufacturer | รายการรถที่ผลิตเสร็จแล้วพร้อมปุ่มกดโอนไปยัง Dealer |
| D-02 | หน้าสต็อกสินค้า (Inventory) | Dealer | แสดงรายการรถในสต็อกพร้อมรูปภาพและสถานะปัจจุบัน |
| D-03 | หน้าการขายและโอนรถ | Dealer | UI สำหรับกรอก Address ผู้ซื้อและทำธุรกรรมการขาย |
| D-07 | อัปโหลดเอกสารการขาย | Dealer | UI สำหรับลากวางไฟล์สัญญาซื้อขายและใบกำกับภาษี |
| C-01 | หน้า "รถของฉัน" (My Garage) | Consumer | แสดงรายการ NFT รถที่เป็นเจ้าของในรูปแบบ Card / List |
| C-02 | หน้าสรุปข้อมูลรถคันโปรด | Consumer | รายละเอียดเชิงลึกของรถ: สเปค, ทะเบียน, ภาษี, ประกัน |
| C-03 | หน้าประวัติรถแบบ Timeline | Consumer | การนำเสนอประวัติการซ่อมและอุบัติเหตุในรูปแบบเส้นเวลา (Timeline) |
| C-04 | หน้าจัดการสิทธิ์ (Consent Mgmt) | Consumer | หน้าที่รวบรวมรายชื่ออู่ที่เคยให้สิทธิ์และปุ่มกดถอนสิทธิ์ |
| C-08 | ระบบ Marketplace / P2P Sale | Consumer | UI สำหรับลงประกาศขายรถและแสดงรายการรถมือสอง |
| C-09 | หน้าจัดการ Escrow | Consumer | UI สำหรับทำรายการวางเงินมัดจำและยืนยันรับรถ |
| DLT-09 | หน้าสรุปข้อมูลทะเบียน (DLT) | DLT Officer | คอนโซลสำหรับเจ้าหน้าที่ขนส่งในการจัดการงานจดทะเบียน |
| DLT-07 | ระบบจัดการ Flag พิเศษ | DLT Officer | UI สำหรับเลือกประเภท Flag และกดส่ง Transaction ล็อกโอน |
| DLT-11 | เครื่องมือค้นหารถอัจฉริยะ | DLT Officer | แถบค้นหาที่รองรับการพิมพ์ VIN หรือ ป้ายทะเบียน |
| F-05 | หน้าจัดการสินเชื่อ (Finance) | Finance | รายการรถที่อยู่ภายใต้การดูแลของไฟแนนซ์และสถานะ Lien |
| I-01 | หน้าจัดการประกันภัย | Insurer | ฟอร์มบันทึกกรมธรรม์และระบบจัดการงานเคลมประกัน |
| S-01 | หน้าบันทึกงานซ่อม (Workshop) | Workshop | อินเทอร์เฟซสำหรับช่างในการบันทึกรายการอะไหล่และไมล์รถ |
| INS-01 | หน้าบันทึกตรวจสภาพ (TorRorOr) | Inspector | ระบบกรอกผลตรวจสภาพ (Pass/Fail) พร้อมอัปโหลดรูปหลักฐาน |
| ALL | หน้าแสดงสถานะธุรกรรม | All Roles | สรุปประวัติการทำรายการล่าสุด (Recent Transactions) บน Blockchain |
