# 📋 Use Cases ของแต่ละ Role — ระบบ Blockchain VIN

> เอกสารนี้รวบรวม **Use Cases ทั้งหมด** ที่แต่ละ Role ควรทำได้ในระบบบริหารจัดการรถยนต์ด้วย Blockchain  
> **ไม่ได้อ้างอิงโค้ดปัจจุบัน** — เป็นข้อกำหนดเชิงธุรกิจ (Business Requirements)

---

## สรุป Roles ทั้งหมดในระบบ

| # | Role | คำอธิบาย |
|---|------|----------|
| 1 | **Admin** | ผู้ดูแลระบบสูงสุด |
| 2 | **Manufacturer** | ผู้ผลิตรถยนต์ / โรงงาน |
| 3 | **Dealer** | ตัวแทนจำหน่าย / เต็นท์รถ |
| 4 | **Consumer** | เจ้าของรถ / ผู้ใช้ทั่วไป |
| 5 | **DLT Officer** | เจ้าหน้าที่กรมการขนส่งทางบก |
| 6 | **Finance / Lender** | สถาบันการเงิน / ไฟแนนซ์ |
| 7 | **Insurer** | บริษัทประกันภัย |
| 8 | **Service Provider (Workshop)** | ศูนย์บริการ / อู่ซ่อมรถ |
| 9 | **Inspector** | สถานตรวจสภาพรถ (ตรอ.) |

---

## 1. 🔑 Admin (ผู้ดูแลระบบ)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| A-01 | จัดการ Role ของผู้ใช้ | เพิ่ม / ลบ Role ให้ wallet address ต่าง ๆ (Grant / Revoke Role) |
| A-02 | กำหนดค่าพารามิเตอร์ระบบ | ตั้งค่าต่าง ๆ เช่น อายุสูงสุดของผลตรวจสภาพ (Inspection Max Age) |
| A-03 | ดู Dashboard ภาพรวมระบบ | ดูจำนวนรถทั้งหมด, จำนวนธุรกรรม, สถิติแต่ละ Role |
| A-04 | จัดการ Smart Contract | Deploy, Upgrade หรือ Pause contract ในกรณีฉุกเฉิน |
| A-05 | แก้ไขปัญหาฉุกเฉิน | ปลดล็อกการโอนรถในกรณีพิเศษ, ยกเลิก Escrow ที่ค้างอยู่ |
| A-06 | ดู Audit Log | ตรวจสอบ transaction ทั้งหมดที่เกิดขึ้นในระบบ |
| A-07 | จัดการ Lien กรณีพิเศษ | ปลดภาระผูกพัน หรือ ตั้งสถานะ Default กรณีจำเป็น |

## 2. 🏭 Manufacturer (ผู้ผลิตรถยนต์)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| M-01 | ลงทะเบียนรถใหม่ (Mint Vehicle NFT) | สร้าง NFT ตัวตนรถใหม่จากสายการผลิต โดยระบุ VIN, รุ่น, สเปค, วันที่ผลิต |
| M-02 | กรอกข้อมูล VIN | ระบุหมายเลขตัวถัง (Vehicle Identification Number) ที่ไม่ซ้ำกัน |
| M-03 | กรอกข้อมูลรุ่นรถ | ระบุยี่ห้อ, รุ่น, ปีที่ผลิต, ประเภทรถ |
| M-04 | กรอกข้อมูลสเปครถ | ระบุขนาดเครื่องยนต์, ประเภทเชื้อเพลิง, สี, จำนวนที่นั่ง, น้ำหนัก ฯลฯ |
| M-05 | กำหนดการรับประกัน (Warranty) | ระบุรายละเอียดการรับประกันจากโรงงาน (ระยะเวลา, เงื่อนไข, ความคุ้มครอง) |
| M-06 | โอนรถไปยัง Dealer | โอน NFT จากโรงงานไปยังตัวแทนจำหน่าย (Inventory Transfer) |
| M-07 | ดูรายการรถที่ผลิตแล้ว | ดูรายการ NFT ทั้งหมดที่โรงงานเป็นผู้ผลิต พร้อมสถานะ |
| M-08 | ดูรายละเอียดรถ | ดูข้อมูล VIN, รุ่น, สเปค, สถานะการจดทะเบียน ของแต่ละคัน |
| M-09 | Recall / เรียกคืนรถ | แจ้งเตือน Recall สำหรับรถรุ่นที่มีปัญหา |

## 3. 🏪 Dealer (ตัวแทนจำหน่าย)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| D-01 | รับรถจาก Manufacturer | รับ NFT ที่ถูกโอนมาจากโรงงาน เพิ่มเข้า Inventory |
| D-02 | ดู Inventory รถในสต็อก | ดูรายการรถทั้งหมดที่อยู่ในความครอบครอง |
| D-03 | ขายรถ (First Sale) | บันทึกการขายรถให้ผู้ซื้อ (Consumer) ครั้งแรก พร้อมโอน NFT |
| D-04 | บันทึกเอกสาร Disclosure | บันทึกข้อมูลที่เปิดเผยก่อนขาย (ประวัติอุบัติเหตุ, น้ำท่วม, สถานะภาระผูกพัน) |
| D-05 | โอนรถระหว่าง Dealer | โอน NFT ระหว่าง Dealer (Trade-in, ย้ายสาขา) |
| D-06 | ดูประวัติรถ | ดูประวัติทั้งหมดของรถ (การซ่อม, ประกัน, เคลม, การโอน) |
| D-07 | จัดการเอกสารการขาย | แนบสัญญาซื้อขาย, ใบกำกับภาษี |
| D-08 | ดูรายละเอียดรถ | ดูข้อมูลจดทะเบียน, สถานะ, ภาระผูกพัน, ผลตรวจสภาพ |
| D-09 | รับรถ Trade-in | รับรถสมือสองจาก Consumer เพื่อนำกลับมาขาย |

## 4. 🚗 Consumer (เจ้าของรถ / ผู้ใช้ทั่วไป)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| C-01 | ดูรายการรถที่เป็นเจ้าของ | ดูรายการ NFT ที่อยู่ใน Wallet ของตน |
| C-02 | ดูรายละเอียดรถ | ดูข้อมูลทั้งหมด: VIN, รุ่น, สเปค, สถานะจดทะเบียน, ภาษี, ป้ายทะเบียน |
| C-03 | ดูประวัติรถ (Vehicle History) | ดูประวัติทั้งหมดบน Blockchain: การซ่อม, การเปลี่ยนอะไหล่, ประกัน, เคลม, การโอน |
| C-04 | อนุญาตอู่เขียนข้อมูล (Grant Write Consent) | ให้สิทธิ์อู่ซ่อม/ศูนย์บริการในการบันทึกประวัติซ่อมบำรุง |
| C-05 | เพิกถอนสิทธิ์อู่ (Revoke Write Consent) | ยกเลิกสิทธิ์ที่ให้กับอู่ซ่อมเมื่อไม่ต้องการแล้ว |
| C-06 | ขายรถ / โอนกรรมสิทธิ์ | โอน NFT ไปยังผู้ซื้อ พร้อมบันทึกสัญญาซื้อขายบน Blockchain |
| C-07 | บันทึก Disclosure ก่อนขาย | เปิดเผยข้อมูลสำคัญแก่ผู้ซื้อก่อนทำการขาย |
| C-08 | สร้าง Escrow สำหรับขายแบบ P2P | สร้าง Escrow contract สำหรับการซื้อขายระหว่างบุคคลอย่างปลอดภัย |
| C-09 | วางเงินเข้า Escrow (ฝั่งผู้ซื้อ) | วางเงินมัดจำผ่าน Escrow (native coin หรือ ERC-20) |
| C-10 | ยกเลิก Escrow | ยกเลิก Escrow ในกรณีที่ยังไม่มีการ fund (ทั้งผู้ซื้อและผู้ขายยกเลิกได้) |
| C-11 | Fulfill เงื่อนไข Escrow | ยืนยันเงื่อนไขที่ตกลงไว้ (เช่น ยืนยันการชำระเงิน) |
| C-12 | ดูสถานะภาระผูกพัน (Lien) | ดูว่ารถมีภาระผูกพันจากไฟแนนซ์หรือไม่ |
| C-13 | ดูสถานะ Flag | ดูว่ารถมี Flag ใด ๆ หรือไม่ (รถหาย, ยึด, น้ำท่วม, Total Loss) |
| C-14 | ดูสถานะ Escrow | ดูรายละเอียดและสถานะ Escrow ที่เกี่ยวข้องกับรถของตน |
| C-15 | ตรวจสอบการรับประกัน (Warranty) | ดูสถานะและรายละเอียดการรับประกันจากโรงงาน |

## 5. 🏛️ DLT Officer (เจ้าหน้าที่กรมการขนส่งทางบก)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| DLT-01 | จดทะเบียนรถ | จดทะเบียนรถครั้งแรก โดยระบุหมายเลขสมุดทะเบียน (Green Book) และเอกสารประกอบ |
| DLT-02 | เปลี่ยนสถานะทะเบียน | เปลี่ยนสถานะการจดทะเบียน: ระงับ (Suspend), ยกเลิก (Cancel), จดทะเบียนใหม่ (Re-register) |
| DLT-03 | ออกป้ายทะเบียน | บันทึกการออกป้ายทะเบียนครั้งแรก |
| DLT-04 | เปลี่ยนป้ายทะเบียน | บันทึกการเปลี่ยนป้ายทะเบียน |
| DLT-05 | แจ้งป้ายทะเบียนหาย | บันทึกการแจ้งป้ายทะเบียนสูญหาย |
| DLT-06 | บันทึกการชำระภาษีประจำปี | บันทึกการจ่ายภาษีรถประจำปี โดยระบุปีภาษี, วันหมดอายุ, ใบเสร็จ |
| DLT-07 | ตั้ง Flag (เช่น รถหาย, ยึด, น้ำท่วม) | ตั้ง Flag บนรถ เพื่อระบุสถานะพิเศษ (Stolen, Seized, Major Accident, Flood, Total Loss, Scrapped) |
| DLT-08 | ปลด Flag | ถอด Flag ที่เคยตั้งไว้ เมื่อปัญหาได้รับการแก้ไข |
| DLT-09 | ดูรายละเอียดรถ | ดูข้อมูลการจดทะเบียน, ป้ายทะเบียน, ภาษี, Flag ของรถ |
| DLT-10 | ดูรายการรถที่จดทะเบียนแล้ว | ดูรายการรถทั้งหมดที่ผ่านการจดทะเบียน |
| DLT-11 | ค้นหารถ | ค้นหารถจากหมายเลขทะเบียน, VIN หรือ Token ID |
| DLT-12 | ล็อก/ปลดล็อกการโอนรถ | ล็อกหรือปลดล็อกการโอนรถผ่านการตั้ง Flag (Auto-lock เมื่อตั้ง Stolen/Seized/Total Loss) |

## 6. 💰 Finance / Lender (สถาบันการเงิน)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| F-01 | สร้างภาระผูกพัน (Create Lien) | สร้างภาระผูกพันบนรถ เมื่อมีสัญญาสินเชื่อ/ไฟแนนซ์ พร้อมล็อกการโอนอัตโนมัติ |
| F-02 | ปลดภาระผูกพัน (Release Lien) | ปลดภาระผูกพันเมื่อผู้กู้ชำระครบ พร้อมปลดล็อกการโอน |
| F-03 | ตั้งสถานะ Default | ตั้งสถานะผิดนัดชำระ (Default) เมื่อผู้กู้ไม่ชำระตามกำหนด |
| F-04 | Fulfill เงื่อนไข Escrow | ยืนยันเงื่อนไขใน Escrow เช่น ปลด Lien เพื่อให้การซื้อขายดำเนินการต่อ |
| F-05 | ดูรายการ Lien ที่ Active | ดูภาระผูกพันทั้งหมดที่อยู่ในสถานะ Active |
| F-06 | ดูรายละเอียด Lien | ดูรายละเอียดของภาระผูกพัน: สถานะ, สัญญา, วันที่เริ่ม, เงื่อนไข |
| F-07 | ดูรายละเอียดรถ | ดูข้อมูลรถที่เกี่ยวข้องกับภาระผูกพัน |
| F-08 | ดู Escrow ที่เกี่ยวข้อง | ดู Escrow ที่มีเงื่อนไข Lien Released เกี่ยวข้อง |

## 7. 🛡️ Insurer (บริษัทประกันภัย)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| I-01 | ออกกรมธรรม์ใหม่ (New Policy) | บันทึกการออกกรมธรรม์ประกันภัยใหม่ โดยระบุเลขกรมธรรม์, ความคุ้มครอง, วันเริ่ม, วันหมดอายุ |
| I-02 | ต่ออายุกรมธรรม์ (Renew Policy) | บันทึกการต่ออายุกรมธรรม์ |
| I-03 | เปลี่ยนแปลงกรมธรรม์ (Change Policy) | บันทึกการเปลี่ยนแปลงรายละเอียดกรมธรรม์ |
| I-04 | ยกเลิกกรมธรรม์ (Cancel Policy) | บันทึกการยกเลิกกรมธรรม์ |
| I-05 | เปิดเคลม (File Claim) | เปิดเคลมประกัน โดยระบุหลักฐาน, ระดับความรุนแรง (Minor/Major/Structural/Total Loss) |
| I-06 | อัปเดตสถานะเคลม | อัปเดตสถานะเคลม: Filed → Estimating → Approved → Repairing → Closed / Rejected |
| I-07 | บันทึก Generic Event | บันทึก event ทั่วไปที่เกี่ยวข้องกับประกันภัย |
| I-08 | ดูรายการกรมธรรม์ | ดูรายการกรมธรรม์ทั้งหมดที่เคยออก |
| I-09 | ดูรายการเคลม | ดูรายการเคลมทั้งหมดและสถานะ |
| I-10 | ดูรายละเอียดรถ | ดูข้อมูลรถที่เกี่ยวข้องกับกรมธรรม์หรือเคลม |
| I-11 | ดูประวัติรถ | ดูประวัติทั้งหมดของรถเพื่อประเมินความเสี่ยง |

## 8. 🔧 Service Provider / Workshop (ศูนย์บริการ / อู่ซ่อมรถ)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| S-01 | บันทึกประวัติซ่อมบำรุง | บันทึกรายการซ่อม: ระยะทาง, รายละเอียดการซ่อม, อะไหล่ที่เปลี่ยน, ระดับอุบัติเหตุ |
| S-02 | ตรวจสอบ Write Consent | ตรวจสอบว่าเจ้าของรถได้อนุญาตให้สิทธิ์การเขียนข้อมูลแล้วหรือไม่ |
| S-03 | บันทึกข้อมูลอะไหล่ | บันทึกรายละเอียดอะไหล่ที่เปลี่ยน (Parts Hash) |
| S-04 | บันทึกเลขไมล์ (Odometer) | บันทึกระยะทางเลขไมล์ ณ เวลาเข้ารับบริการ |
| S-05 | บันทึกระดับความเสียหายจากอุบัติเหตุ | ระบุระดับอุบัติเหตุ: None, Minor, Major, Structural |
| S-06 | บันทึก Generic Event | บันทึก event ทั่วไปที่เกี่ยวกับการบริการรถ |
| S-07 | ดูรายละเอียดรถ | ดูข้อมูลรถที่เข้ารับบริการ |
| S-08 | ดูประวัติการซ่อมที่ผ่านมา | ดูประวัติการซ่อมบำรุงก่อนหน้าของรถคันนั้น |
| S-09 | ดูรายการงานที่ตนบันทึก | ดูรายการบันทึกซ่อมบำรุงทั้งหมดที่ตนเองเป็นผู้บันทึก |

## 9. 🔍 Inspector / ตรอ. (สถานตรวจสภาพรถ)

### Use Cases

| # | Use Case | รายละเอียด |
|---|----------|------------|
| INS-01 | บันทึกผลตรวจสภาพ | บันทึกผลตรวจสภาพรถ: ผ่าน (Pass) หรือ ไม่ผ่าน (Fail) |
| INS-02 | บันทึกข้อมูลตัวชี้วัด (Metrics) | บันทึก hash ของข้อมูลตัวชี้วัดการตรวจ (เช่น ค่ามลพิษ, ระบบเบรก) |
| INS-03 | ออกใบรับรองผลตรวจ | บันทึก hash ของใบรับรองผลตรวจสภาพ |
| INS-04 | ดูรายละเอียดรถ | ดูข้อมูลรถที่เข้ารับการตรวจ |
| INS-05 | ดูประวัติการตรวจสภาพ | ดูประวัติการตรวจสภาพก่อนหน้าของรถ |
| INS-06 | ดูรายการตรวจสภาพที่ตนบันทึก | ดูผลการตรวจสภาพทั้งหมดที่ตนเองเป็นผู้ตรวจ |

## Cross-Role Use Cases (กรณีข้าม Role)

| # | Use Case | Roles ที่เกี่ยวข้อง | รายละเอียด |
|---|----------|-------------------|------------|
| X-01 | กระบวนการขายรถใหม่ | Manufacturer → Dealer → Consumer → DLT Officer | ผลิต → โอนไป Dealer → ขายให้ Consumer → จดทะเบียน |
| X-02 | การซื้อขายรถมือสอง P2P | Consumer (ผู้ขาย) ↔ Consumer (ผู้ซื้อ), Finance | Disclosure → สร้าง Escrow → ปลด Lien → Fund → Release |
| X-03 | กระบวนการเคลมประกัน | Consumer → Insurer → Workshop | เปิดเคลม → ประเมิน → อนุมัติ → ส่งซ่อม → ปิดเคลม |
| X-04 | กระบวนการต่อภาษี | Consumer → Inspector → DLT Officer | ตรวจสภาพ (ตรอ.) → ผ่าน → ชำระภาษี (DLT) |
| X-05 | การจัดไฟแนนซ์ | Consumer → Finance → DLT Officer | ทำสัญญาสินเชื่อ → สร้าง Lien → ล็อกโอน |
| X-06 | การซ่อมบำรุง | Consumer → Workshop | ให้ Consent → อู่บันทึกผล → เพิกถอน Consent |
| X-07 | รถถูกขโมย | Consumer → DLT Officer | แจ้งรถหาย → ตั้ง Flag Stolen → ล็อกโอนอัตโนมัติ |

> บาง Use Case อาจยังไม่ได้ implement หรืออาจต้องปรับปรุงเพิ่มเติม
