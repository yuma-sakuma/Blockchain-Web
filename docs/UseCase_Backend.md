# 🖥️ Use Cases: Backend Layer

> เอกสารนี้รวบรวม Use Cases ที่ทำงานในระดับ **Backend / API / Off-chain Data**  
> เน้นการจัดการข้อมูลขนาดใหญ่, การทำดัชนี (Indexing), การยืนยันตัวตน และการเก็บเอกสาร

| ID | Use Case | บทบาท (Role) | รายละเอียดทางเทคนิค (Backend) |
|---|----------|-------------|-----------------------------|
| A-03 | Dashboard ภาพรวมระบบ | Admin | รวบรวมข้อมูลดิบจาก Blockchain มาสรุปสถิติและแสดงผล |
| A-06 | ดู Audit Log | Admin | ดึงประวัติการเรียกใช้ API และ Transaction มาจัดเก็บใน DB |
| M-02 | จัดการข้อมูล VIN (Plain) | Manufacturer | เก็บหมายเลขตัวถังแบบตัวอักษรดิบ (เนื่องจากในโซ่เก็บเฉพาะ Hash) |
| M-03 | จัดการข้อมูลรุ่นและสเปค | Manufacturer | เก็บ JSON Metadata ของรุ่นรถและสเปคอย่างละเอียด |
| M-05 | จัดการข้อมูลการรับประกัน | Manufacturer | เก็บเงื่อนไขและรายละเอียด Warranty แบบสมบูรณ์ |
| M-09 | เรียกคืนรถ (Recall) | Manufacturer | จัดการแจ้งเตือนและระบบคัดกรองรถรุ่นที่ต้อง Recall |
| D-02 | จัดการ Inventory รถ | Dealer | Sync ข้อมูล NFT ในสต็อกมาเป็นรายการสินค้าในระบบ |
| D-07 | จัดการเอกสารการขาย | Dealer | จัดเก็บใบกำกับภาษี, สัญญาซื้อขาย (PDF / CID Storage) |
| C-03 | ดูประวัติรถ (Vehicle History) | Consumer | รวบรวม Events ทั้งหมดมาประมวลผลเป็น Timeline ประวัติรถ |
| C-14 | ตรวจสอบสถานะ Escrow | Consumer | ดึงสถานะและรายละเอียดเงื่อนไข Escrow มาแสดงผล |
| C-15 | ตรวจสอบการรับประกัน | Consumer | ตรวจสอบระยะเวลาประกันคงเหลือและเงื่อนไขการเคลม |
| DLT-09 | ดูรายละเอียดรถ | DLT Officer | รวมข้อมูล On-chain และ Off-chain (รูปภาพ, เอกสาร) มาแสดงผล |
| DLT-10 | แสดงรายการรถจดทะเบียน | DLT Officer | ทำ Indexing รายการรถทังหมดเพื่อให้ค้นหาได้รวดเร็ว |
| DLT-11 | ระบบค้นหารถ | DLT Officer | ค้นหาจาก VIN Plain Text, ป้ายทะเบียนดิบ หรือชื่อเจ้าของ |
| F-05 | ดูรายการ Lien ที่ Active | Finance | กรองรายการรถที่มีภาระผูกพันกับสถาบันการเงินนั้น ๆ |
| F-06 | จัดการข้อมูลสินเชื่อ | Finance | เก็บรายละเอียดสัญญาเงินกู้, อัตราดอกเบี้ย, งวดชำระ |
| I-08 | จัดการข้อมูลกรมธรรม์ | Insurer | เก็บไฟล์กรมธรรม์และรายละเอียดความคุ้มครองปลีกย่อย |
| I-09 | จัดการข้อมูลเคลม | Insurer | เก็บรูปภาพความเสียหาย, ใบประเมินราคา, รายการอะไหล่เคลม |
| I-11 | ประเมินความเสี่ยงจากประวัติ | Insurer | วิเคราะห์ประวัติรถจากข้อมูลในอดีตเพื่อคำนวณเบี้ยประกัน |
| S-02 | ตรวจสอบสิทธิ์ Consent | Workshop | ตรวจสอบความถูกต้องและวันหมดอายุของสิทธิ์จาก Cache/DB |
| S-08 | จัดการประวัติบริการย้อนหลัง | Workshop | เก็บรูปภาพการซ่อม, ใบเสร็จรับเงิน, รายละเอียดช่างผู้ซ่อม |
| S-09 | จัดการงานบริการในศูนย์ | Workshop | ระบบจัดการคิวและบันทึกงานซ่อมบำรุงประจำวัน |
| INS-04 | จัดการใบรับรองการตรวจ | Inspector | จัดเก็บเอกสาร PDF ใบรับรอง ตรอ. และข้อมูลดิบจากการตรวจ |
| INS-06 | แสดงรายการตรวจสภาพ | Inspector | ทำรายการผลการตรวจทังหมดที่เคยดำเนินการ |
| ALL | การยืนยันตัวตน (Wallet Auth) | All Roles | จัดการ Session และการผูก Wallet Address กับสิทธิ์ที่ได้รับในโครงการ |
| ALL | ระบบแจ้งเตือน (Notify) | All Roles | ส่งอีเมลหรือ Notification เมื่อเกิดเหตุการณ์สำคัญ (เช่น โอนรถ) |
